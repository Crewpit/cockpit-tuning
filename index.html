Zram Efficiency

Zram Stress Test

Fills a temporary scratch zram device so you can watch compression and the charts. RAM use is hard-capped, your real swap is untouched, and the device is removed afterwards. It does not force real swapping, so swap in/out charts will not move. Defaults are conservative.

Warning: Improperly configured options (high RAM cap, large fills of incompressible data, very short write durations) can freeze the whole system and require a hardware reboot.
